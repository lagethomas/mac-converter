# Conversor de MAC Address

Uma extensão simples e eficiente para converter **MAC Addresses** em diferentes formatos comuns usados em equipamentos de rede, sistemas e documentações.

## ✨ Funcionalidades

- Inserção de um **MAC Address** em qualquer formato válido.  
- Geração automática de variações comuns:
  - Hífens → `00-05-16-59-94-C9`
  - Dois pontos → `00:05:16:59:94:C9`
  - Cisco (pontos) → `0005.1659.94C9`
  - Sem separadores → `0005165994C9`
  - Espaços → `00 05 16 59 94 C9`
  - Formato HP → `000516-5994C9`
  - Grupos de 4 caracteres → `0005-1659-94C9`
- Clique em qualquer resultado para **copiar automaticamente** para a área de transferência.  
- Exibe uma mensagem visual de confirmação após a cópia.  

## 🚀 Benefícios

- Evita erros de digitação ao converter formatos de MAC.  
- Útil para **técnicos de redes, sysadmins e engenheiros** que trabalham com equipamentos de diferentes fabricantes.  
- Interface simples, rápida e responsiva.  

## 📦 Instalação

### 🔹 Google Chrome
1. Clone ou baixe este repositório.  
2. No navegador, acesse:  

chrome://extensions/

3. Ative o **Modo do desenvolvedor** (canto superior direito).  
4. Clique em **"Carregar sem compactação"**.  
5. Selecione a pasta do projeto.  
6. A extensão estará disponível no menu de extensões do Chrome.  

### 🔹 Microsoft Edge
1. Clone ou baixe este repositório.  
2. No navegador, acesse:

edge://extensions/

3. Ative o **Modo do desenvolvedor** (canto inferior esquerdo).  
4. Clique em **"Carregar sem compactação"**.  
5. Selecione a pasta do projeto.  
6. A extensão aparecerá no menu de extensões do Edge.
